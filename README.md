# Sukoon — Verified Partner Washroom Network

**Sukoon** is a verified-open partner washroom network for India, inspired by Germany's *Nette Toilette* civic partnership model. Instead of waiting years to construct new standalone blocks, Sukoon partners with existing cafes, petrol pumps, retail stores, and shopping arcades to open their washrooms to everyone, pays them a monthly cleaning stipend (`₹3,500–₹4,000/mo` via UPI), and verifies quality through 10-second anonymous QR user ratings.

## Quick Start & Run Commands

```bash
# 1. Install dependencies
npm install

# 2. Start the development server (runs at http://localhost:3000)
npm run dev

# 3. Optional: Build and run production bundle
npm run build
npm start
```

> **Offline Capability:** All seed data (`/data/seed.ts`), state management, icons, and styles run 100% locally offline (only OpenStreetMap tiles fetch over the network when online). No API keys or accounts required.
